# Modelos do cubo de partículas

Os modelos 3D que os pontos do Hero formam ao clicar no cubo (`CubeField`).
Cada clique passa para o próximo modelo, e depois do último volta ao cubo.

- Formato: `.glb` (glTF binário), sem compressão Draco/meshopt.
- A ordem dos cliques segue a ordem alfabética dos arquivos: use um prefixo
  numérico para escolher (`01-cafe.glb`, `02-guitarra.glb`).
- Estes arquivos são a fonte e não vão para o site. Um script transforma cada
  modelo numa nuvem de alguns milhares de pontos (poucos KB), e só essa nuvem
  é publicada.
