# Fase 3, segunda leva — Hover nos links e na lista de trabalhos — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Sublinhado que corre e magnético nos quatro links de ação, tira de capas no CTA primário, cartão de destino nos canais do contato, miniatura em cada ficha e reação tipográfica na lista — com o motion inteiro desligado em reduced motion.

**Architecture:** Um componente novo, `ActionLink`, é o link de ação: desenha o traço (um `span` animado só por `transform`), aplica o magnético (hook que escreve `--magnet-x/--magnet-y` no evento de ponteiro, sem laço de rAF) e aceita uma prévia decorativa irmã do `<a>`. `ProjectThumb` desenha a capa ou o placeholder e serve à ficha e à tira. Toda `transition`/`animation` nova fica dentro de `@media (prefers-reduced-motion: no-preference)`, todo hover dentro de `@media (hover: hover) and (pointer: fine)`, e todo elemento com duração leva `data-motion`.

**Tech Stack:** React 19, React Router 8, Vite 8, TypeScript 5.9, CSS Modules, Vitest 5 + Testing Library + jsdom, Playwright 1.64.

**Spec:** `docs/superpowers/specs/2026-10-27-fase-3-hover-design.md`. Referência visual: `docs/fase-3/prototipo/hover.html` (abre na configuração aprovada; o painel mostra as opções recusadas — ignorá-las).

## Global Constraints

- Branch `fase-3-segunda-leva`. Nenhuma dependência nova.
- **Valores aprovados:** curva `cubic-bezier(0.2, 0.7, 0, 1)`; traço corre em 0,7 s (sai pela direita encolhendo com origem à direita até 45 %, volta crescendo com origem à esquerda); magnético `x = 0,25 × dx`, `y = 0,35 × dy` (px, distância ao centro do link); reação: título `translateX(clamp(16px, 3vw, 48px))`, outras fichas opacidade 0,35; miniatura 4:3, 168 px de largura a partir de 768 px, `scale(1.06)` no hover/foco; demais durações entre 0,3 e 0,7 s.
- **Em repouso nada muda** em relação ao Gate 2 nos quatro links (traços, cores, espessuras). Em hover/foco o traço termina em `--accent` e a cor do texto não muda.
- **Hover** de todos os efeitos só sob `@media (hover: hover) and (pointer: fine)`. **Foco** (`:focus-visible`, `:focus-within`) vale sempre.
- **`transition`/`animation`** só dentro de `@media (prefers-reduced-motion: no-preference)` (ou a regra já existente da entrada). Com reduce, os estados finais aparecem na hora.
- **Todo elemento com duração leva `data-motion`.** Valores: `action-link`, `trace`, `peek`, `thumb`, `slip`, `slip-title`.
- **Prévias** (tira e cartão) e miniaturas são `aria-hidden`, `pointer-events: none` nas prévias; escondidas em repouso com `visibility: hidden` + `opacity: 0` (o axe não mede texto invisível), saindo com `transition: opacity …, visibility 0s <duração>`.
- **Magnético:** só `pointerType === 'mouse'`; nunca com reduced motion; sem laço de rAF; nunca escreve no bloco `.actions` do hero (que tem o `transform` da abertura).
- **Fora do escopo:** links "Repositório"/"Demo" das fichas, links do case study, Release, barra superior. `ExternalLink` não muda.
- **Nenhuma string voltada ao usuário em componente.** Endereço do cartão = `href` sem `https://`.
- **Viewports:** 1440×900, 768×1024, 390×844, nos dois idiomas.
- **Verificação sem `rtk`:** `pnpm typecheck`, `pnpm lint`, `pnpm test`, `pnpm build:preview`, `pnpm test:e2e`, lendo o exit code com `; echo "exit=$?"`. (`pnpm build` e `pnpm validate` falham por desenho enquanto houver mock — ver `docs/BACKLOG.md`.) Toda verificação nova é vista falhando uma vez antes de o verde valer.
- **Servidor de preview velho:** o Playwright reaproveita um servidor já aberto na porta 4173 (`reuseExistingServer`), que pode estar servindo um build antigo. Antes de rodar e2e, confira que nada escuta na 4173 ou pare o servidor.
- Commits em português, `tipo: descrição`, como o histórico, terminando com `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. **Toque num celular** (tap numa ficha, num CTA): nada fica preso — sem esmaecimento, sem tira, sem cartão, sem zoom; o tap navega normalmente. Teste na Task 5.
2. **A tira cobrindo o hero:** nas três faixas, a caixa da tira visível não pode cruzar o `h1`, a função, o statement nem o CTA secundário. Teste na Task 4.
3. **Hover no meio da abertura** (página já rolada, bloco dos CTAs subindo e apagando): o magnético move o link e a abertura move o bloco, sem um apagar o outro. Teste na Task 4.
4. **Trocar de idioma com o mouse parado sobre um link:** o link remontado não fica deslocado (`--magnet-*` volta a 0). Teste unitário na Task 2.
5. **Leitor de tela:** os nomes acessíveis dos quatro links e dos títulos das fichas não mudam (nada das prévias, miniaturas ou placeholders entra neles). Testes nas Tasks 3 e 4.
